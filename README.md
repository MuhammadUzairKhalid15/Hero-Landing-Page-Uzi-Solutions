# Hero Landing Page

A responsive hero/landing page built with HTML & CSS — featuring a fixed navbar, full-screen background image with a dark overlay, bold headline, and call-to-action buttons.

🔗 **Live Demo:** https://hero-landing-uzi-solutions.netlify.app/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Hero-Landing-Page-Uzi-Solutions

## ✨ Features

- 🧭 Fixed navbar with gradient hover effect on links
- 🖼️ Full-screen background image with a dark overlay for text contrast
- 📝 Bold centered headline and subheading
- 🔘 Two styled call-to-action buttons ("Learn more" & "Subscribe")
- 🎨 Custom Google Fonts (Poppins)

## 🔧 Built With

- **HTML5**
- **CSS3** – flexbox, positioning, background images, hover transitions

## 💡 What I Practiced

- Building a fixed navbar with `position: fixed` and `z-index`
- Layering a dark overlay on a background image using a pseudo-element
- Centering content absolutely with `transform: translate(-50%, -50%)`
- Styling interactive button hover states with smooth transitions
